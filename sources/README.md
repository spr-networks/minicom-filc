# Minicom source snapshot

`minicom-master.tar.gz` is the Minicom 2.12-dev source snapshot used for this build. Its SHA-256 is `f046c1029df82fa18f2da6093cd4ffeecb49fb6339d5fd00b6956bccf603af45`. The upstream project is [minicom-team/minicom](https://salsa.debian.org/minicom-team/minicom). The archive contains Minicom's GPL-2.0-or-later `COPYING` file.

The exact archive is kept here so CI builds the same source on both architectures.
